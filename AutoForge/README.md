# AutoForge (Unity 6)

Factorio/Mindustry/Omega Crafters/Create-подобная песочница: автоматизация производства,
программируемые процессоры, волны врагов, дерево исследований до Реактора.

## Как запустить
1. Откройте папку `AutoForge` в **Unity 6** (Hub -> Open project). Первый импорт создаст `.meta`-файлы.
2. Создайте пустую сцену и сохраните как `Assets/Scenes/Main.unity` (или File -> Build Settings -> Add Open Scenes).
   Вся сцена генерируется кодом (`Boot.cs` через `RuntimeInitializeOnLoadMethod`) — ничего перетаскивать не нужно.
3. Press Play.

## Управление
- WASD — движение; колесо мыши / 1..9 — выбор машины; R — поворот конвейера
- ЛКМ — строить / выбрать; Ctrl+ЛКМ по процессору — открыть редактор кода; Q+ЛКМ или ПКМ — снести
- E — подобрать предметы; Space — удар; F5 — рестарт

## Системы
- Тик мира 10 Гц (детерминированный, как сеть Factorio)
- Цепочки ресурсов: Камень ->(Дробилка)-> Гравий ->(Промывка)-> Самородок+Кремний ->(Пресс/Плавильня)-> Железо -> Сталь -> Схемы -> Чипы -> Турели -> Лаборатория -> Реактор (победа)
- Процессор: мини-ассемблер (SET/MOV/ADD/CMP/JEQ/IN/OUT/FIRE), датчики врагов, сигналы соседям
- Враги: Raider (ломает машины, бьёт игрока), Harvester (ест руду, плюётся снарядами); дроны роняют трофеи
